# Rasterize Pro

**A simple rasterization tool for Adobe Illustrator.**

Rasterize selected artwork into individual images with customizable resolution and background settings.

**Developed by [Ibraheem Sabbah](https://www.linkedin.com/in/ibraheem-sabbah/)**

## Features ⭐

- Rasterize selected objects individually.
- Choose resolution: **2400, 1200, 600, 300, 150, or 72 DPI**.
- Choose between **Transparent** and **White** backgrounds.
- View a summary of successful conversions and errors.
- Supports text, vector artwork, images, and groups where supported by Illustrator.

## Installation

### Quick Start

1. Download `Rasterize_Pro.jsx` from this repository.
2. Open Adobe Illustrator and select the objects you want to rasterize.
3. Go to **File → Scripts → Other Script**.
4. Select `Rasterize_Pro.jsx`.

### Permanent Installation

1. Copy `Rasterize_Pro.jsx` into your Illustrator `Scripts` folder.
2. Restart Illustrator.
3. Find **Rasterize Pro** under **File → Scripts**.

## How to Use

1. Select your artwork.
2. Run **Rasterize Pro**.
3. Choose your resolution and background.
4. Click **Rasterize**.

**Tip:** Save a backup of your Illustrator document before rasterizing. Converted objects are no longer editable as their original vector or text elements.

## Troubleshooting

- **No objects processed:** Make sure the intended artwork is selected.
- **Conversion failed:** Check whether the object is locked, hidden, or part of a complex group.
- **Dimensions changed slightly:** Check the final dimensions after rasterization.
